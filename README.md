# MKS Architecture Framework Docs

Documentation for the **MKS Architecture Framework**, a lightweight administrative and server-management framework for Krunker maps.

The framework was developed from practical Krunker map development experience and focuses on providing essential systems while minimizing unnecessary script size and complexity.

## About

Krunker maps have a **500,000-character game data limit**. Large administrative systems can use a significant portion of this limit, making it important to keep scripts lightweight and modular.

The MKS Architecture Framework provides a foundation for commonly needed systems, including:

- Server administration
- Permission management
- Player validation
- Logging
- Server-client communication
- Administrative controls

The framework does not attempt to include every possible feature. Instead, it provides a practical foundation that can be modified and expanded based on the requirements of a map or project.
