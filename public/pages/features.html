Core Features

The MKS Architecture Framework includes several core features for managing players, administrative actions, permissions, server controls, and logging.

Admin Panel

The Admin Panel is the main interface for accessing the framework's administrative tools, player management features, and server systems. It is available to players with the Admin, Temporary Admin, Temporary Root, or Root role.

Player List

The Player List displays the players currently connected to the server and allows an administrator to select a player for further management or administrative actions. It is available to players with Admin, Temporary Admin, Temporary Root, or Root role.

Player Profile

The Player Profile displays the selected player's profile picture and username or account name. Clicking either the profile picture or name copies the player's name to the clipboard for quick copy-pasting.

Admin and Temporary Admin Tools

These tools provide basic player management actions, including kicking, banning, muting, teleporting to a player, and bringing a player to the administrator's location. They are available only to players with the Admin or Temporary Admin role.

Temporary Root Tools

Temporary Root Tools include all actions available to Admin and Temporary Admin players, with additional access to give points to players. They are available only to players with the Temporary Root role. Temporary Root players cannot grant Temporary Admin or Temporary Root roles.

Root Tools

Root Tools provide the highest level of administrative access in the permission hierarchy. Root players can perform the actions available to Admin, Temporary Admin, and Temporary Root players, and can also grant Temporary Admin and Temporary Root roles to other players. These tools are available only to players with the Root role.

Admin Weapons

Admin Weapons provide access to a variety of weapons, including AK, Sniper, SMG, LMG, Revolver, and others. They are available only to players with the Temporary Root or Root role. Players with the Admin or Temporary Admin role cannot access these weapons.

Mute List

The Mute List displays players who are currently on auto mute and allows Root to remove a player from the list. The Mute List is available only to players with the Root role.

Ban List

The Ban List displays players who have been auto banned and allows Root to remove a player from the list. The Ban List is available only to players with the Root role.

Temporary Admin List

The Temporary Admin List displays players who currently have the Temporary Admin role and allows the role to be removed from a player. This feature is available only to players with the Root role.

Temporary Root List

The Temporary Root List displays players who currently have the Temporary Root role and allows the role to be removed from a player. This feature is available only to players with the Root role.

Admin Controls

Admin Controls provide server-wide administrative actions, including kicking the host, automatically kicking guests, locking the server, muting all guests, and ending the server. When the server is ended, a countdown from 45 seconds to 0 is displayed before all players are kicked. These controls are available only to players with the Root role.

Mini Log

The Mini Log provides a compact view of recent server activity, allowing important events and actions to be monitored without opening the full log interface. It is visible only to players with the Temporary Root or Root role.

Expanded Log

The Expanded Log provides a larger and more detailed view of recorded server activity, making it easier to review multiple events and inspect administrative actions. Players with the Temporary Root or Root role can also click a selected row to copy its log message to the clipboard. The Expanded Log is available only to players with the Temporary Root or Root role.
