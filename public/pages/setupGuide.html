Setup Guide

This guide explains how you can set up and use the MKS Architecture Framework in your map.

Step 1: Create the Triggers

Create five triggers. Set each trigger's size to X: 16, Y: 30, and Z: 16, as shown in the image below. Then configure each trigger's event and action as shown in the corresponding settings images.

Step 2: Create the Objects

Next, create six objects. Set each object's size to X: 16, Y: 30, and Z: 16, as shown in the image.

Step 3: Arrange the Triggers and Objects

Arrange the five triggers and six objects in an alternating pattern. Place an object between each trigger, with one object at both ends, as shown in the image.

Step 4: Create the Front and Back Objects

Create two additional objects. Set each object's size to X: 176, Y: 30, and Z: 16. You will use these objects to form the front and back sides of the setup.

Step 5: Place the Front and Back Objects

Place one of the long objects behind the triggers and objects. Place the other in front of them, as shown in the image.

Step 6: Create the Top and Bottom Objects

Create two more objects. Set each object's size to X: 176, Y: 10, and Z: 16. You will use these objects to form the top and bottom sides of the setup.

Step 7: Place the Top and Bottom Objects

Place one of the objects above the triggers and objects, then place the other below them. Once you have positioned them correctly, the objects should complete the structure shown in the image.

After completing the trigger setup, go to Set Trigger Coordinates to continue configuring the Client and Server scripts.
