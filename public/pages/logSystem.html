Understanding Logs

The MKS Architecture Framework uses categorized logs to describe and track server activity.

Log Format

Each log follows this format:

[CATEGORY] ACTOR :: ACTION :: TARGET

The :: symbol acts as a separator between the main parts of a log.

Part Description
[CATEGORY] Describes the type of event being recorded.
ACTOR Describes the administrator or system that performed the action.
ACTION Describes the action performed by the administrator or system.
TARGET Describes the player, administrator, or system affected by the action.

Example

[PLR] Miekie :: joined :: SERVER

Log Categories

Log categories describe the type of event being recorded. Each log begins with a category tag, making server activity easier to describe and understand.

Server and System Activities

Category Description Example
REQ Request. Records a request sent to the server, such as requesting player data. [REQ] Miekie :: req <bPl> data :: SERVER
NET Network. Records network communication or data sent from the client to the server. [NET] Miekie :: sent valid <bPl> req :: SERVER
SYS System. Records automatic server or system actions, such as automatically banning a player. [SYS] SERVER :: AUTO BAN :: Miekie
SYNC Synchronization. Records synchronization events, such as renewing the player list. [SYNC] SERVER :: PLAYER LIST RENEWED :: has ROOT

Warnings and Errors

Category Description Example
DENY Denied. Records requests or actions that were denied, such as an Admin attempting to ban other Admin. [DENY] Miekie :: BAN DENIED :: Miekie
WRNG Warning. Records potentially problematic or suspicious activity, such as exceeding a request limit. [WRNG] Miekie :: exceeded req limit <bPl> :: SERVER
ERR Error. Records an invalid request, a failed operation, or another unexpected system error. [ERR] Miekie :: sent INVALID REQUEST :: SERVER

Administrative Activities

Category Description Example
ACT Action. Records an administrative action performed by an administrator. [ACT] Miekie :: GO TO :: Player_1
WEP Weapon. Records a weapon-related action, such as giving a weapon to a player. [WEP] Miekie :: GAVE SNIPER :: Player_1
RM Removal. Records a player being removed from a list or role. [RM] Miekie :: REMOVED FROM BAN LIST :: Player_1
TMP Temporary. Records actions involving temporary roles or permissions. [TMP] Miekie :: GRANTED TMP ROOT :: Player1
CTRL Control. Records server control or server-management actions. [CTRL] Miekie :: ENABLED END SERVER :: SERVER

Player Activities

Category Description Example
PLR Player. Records player-related events, such as a player joining or leaving the server. [PLR] Player1 :: joined :: SERVER
VC Voice Chat. Records voice chat-related activity. [VC] Miekie :: USING VOICE CHAT :: SERVER
