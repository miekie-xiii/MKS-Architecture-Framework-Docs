Client and Server Script

The MKS Architecture Framework uses separate Client and Server scripts that work together to manage the framework's systems. The Client handles player-side features and interface elements, while the Server handles administrative logic, permissions, validation, and other server-side systems.

You can customize the framework to fit your needs. You are free to study the scripts, modify existing systems, remove features you do not need, or expand the framework with your own functionality. You can adapt the MKS Architecture Framework to fit the specific requirements of your map or project.
